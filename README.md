# Personal Portfolio Website

*Live at: [brynja-schultz.github.io](https://brynja-schultz.github.io)*

## Overview

This repository contains the source code for my personal portfolio website, designed to showcase my background, skills, and selected projects.
The site is a **work in progress** and will continue to evolve with additional content, improved styling, and expanded functionality.

---

## Current Features

* **Home Page:** Brief introduction and site navigation.
* **About Page:** Overview of my background, education, and interests.
* **Projects Page:** Highlighted coding and academic projects with links to repositories.
* **Resume Page:** Direct access to my resume for recruiters and collaborators.
* **Contact Page:** Methods for getting in touch.

---

## Technical Details

* **Languages:** HTML5, CSS3
* **Structure:** Static site with separate pages for content sections.
* **Assets:** Custom images and icons stored locally.

---

## Planned Enhancements

* Improved responsive design for mobile and tablet devices.
* Enhanced project showcase with detailed descriptions and visuals.
* Light/dark theme toggle.
* Integrated blog section for sharing learning insights.

---

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/brynja-schultz/brynja-schultz.github.io.git
   ```
2. Open `index.html` in your browser.
