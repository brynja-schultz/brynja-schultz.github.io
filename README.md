# Brynja Schultz — Personal Portfolio

A simple static portfolio designed for GitHub Pages and a custom domain such as `brynjaschultz.com`.

## Before publishing

Open `index.html` and replace these placeholders:

- `YOUR_LINKEDIN_URL`
- `YOUR_GOOGLE_SCHOLAR_URL`
- `YOUR_LEGAL_QA_PROJECT_URL`
- `YOUR_EMAIL`

Also:

1. Put your current resume in this folder and name it `resume.pdf`.
2. Replace the research placeholder with your actual paper title and a one-sentence description.
3. Replace the Product Analytics placeholder once that project is complete.

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `personal-website`.
2. Upload `index.html`, `styles.css`, `script.js`, `resume.pdf`, and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. GitHub will give you a temporary Pages URL.
7. Under **Custom domain**, enter your domain, e.g. `brynjaschultz.com`.
8. Add the required DNS records at your domain registrar.
9. Once DNS resolves, enable **Enforce HTTPS**.

## Optional improvements later

- Add a professional headshot only if you want one; it is not necessary.
- Add screenshots/plots for your strongest projects.
- Add analytics only if you care about tracking traffic.
- Keep the site to 3–5 strong projects rather than turning it into a complete archive.
